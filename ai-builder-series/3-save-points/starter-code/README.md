# Save Points — Starter Code

## About This Workshop

Students should use their cleanly separated quiz app from Workshop 2. If a student
missed previous workshops, the files in this folder provide the same starting point.

## Starter Files

- `index.html` — HTML structure
- `styles.css` — Styling
- `questions.js` — Question data
- `script.js` — Game logic

These are the same as Workshop 2's solution — a clean, separated quiz app ready for
new features.

## Solution Reference

The `solution/` folder shows what the quiz app looks like after adding features
through the save-change-test loop. It includes:

- A question counter ("Question 3 of 5")
- A progress bar
- A category label for each question

## Your Mission

Use the save-change-test loop to add features:

1. Commit your current working code
2. Write test cases for your quiz
3. Add a feature using Copilot
4. Run your test cases
5. If passing: commit. If broken: rollback.
6. Repeat!
