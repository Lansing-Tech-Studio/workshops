# Team Up — Starter Code

## About This Workshop

This workshop uses a shared team repository. The instructor should create one
repository per team before the workshop and add all team members as collaborators.

The files in this folder are the baseline that should be in each team's shared
repository. This is the clean, separated quiz app from Workshop 3.

## Starter Files

- `index.html` — HTML structure
- `styles.css` — Styling
- `questions.js` — Question data
- `script.js` — Game logic

## How to Set Up Team Repos (Instructor)

1. Create a new GitHub repository for each team (e.g., `quiz-app-team-1`)
2. Copy these starter files into the repository
3. Add all team members as collaborators (Settings → Collaborators)
4. Each student clones the repo and creates their own branch

## Your Mission

1. Clone your team's repository
2. Create a branch for your feature
3. Build your feature using Copilot (stay in your concern's files!)
4. Commit and push your branch
5. Open a pull request
6. Review a teammate's PR
7. Merge and verify the combined app works
