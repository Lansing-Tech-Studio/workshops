# Team Up — Starter Code

## About This Workshop

This workshop uses a shared **team repository**:
[`Lansing-Tech-Studio/team-quiz-app`](https://github.com/Lansing-Tech-Studio/team-quiz-app).
That repo is the canonical baseline — students fork it and contribute through
pull requests. The files in this folder are a reference copy of the same
clean, separated quiz app.

## Starter Files

- `index.html` — HTML structure
- `style.css` — Styling
- `questions.js` — Question data
- `app.js` — Game logic

## How the Team Repo Works (Instructor)

- The team repo lives in the Lansing-Tech-Studio org with GitHub Pages enabled
  (live at <https://lansingtechstudio.org/team-quiz-app/>)
- Students do **not** get collaborator access — they fork the repo, so no
  permission setup is needed
- Only the instructor can merge PRs into the team repo
- Running more than one team? Create one copy per team — see the
  [Timing Guide](../instructor-notes/timing-guide.md) for the commands

## Your Mission

1. Fork the team repository and open a Codespace on your fork
2. Create a branch for your feature
3. Build your feature using Copilot (stay in your concern's files!)
4. Commit and push your branch to your fork
5. Open a pull request to the team repo
6. Review a teammate's PR
7. After the instructor merges, sync your fork and verify the combined app works
