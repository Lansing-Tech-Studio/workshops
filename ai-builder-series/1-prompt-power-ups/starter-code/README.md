# Prompt Power-Ups — Starter Code

## About This Workshop

Unlike other workshops, there is no pre-written starter code for Workshop 1.
Students generate their own quiz app from scratch using AI prompts. This is
intentional — the process of iterating on prompts to produce working code IS the
workshop.

## What Students Will Build

A simple HTML/CSS/JavaScript quiz app with:

- Multiple choice questions displayed one at a time
- Buttons for answer choices
- Score tracking
- A results screen at the end

## Solution Reference

The `solution/` folder contains an example of what a finished quiz app might look
like after Workshop 1. Students' apps will look different from this — that's
expected and encouraged.

The solution is intentionally "messy" — everything is in a single HTML file or a
small set of files without clean separation. This sets up the motivation for
Workshop 2 (One Thing at a Time), where students will refactor and organize.

## Instructor Notes

- Do NOT give students the solution code. The learning is in the prompting process.
- If a student is stuck, help them improve their prompt, not their code.
- If a student's quiz doesn't work at all by the end, they can use the solution as
  a starting point for Workshop 2.
