# 7. Special Needs resource website

Project-specific gaps. Also ask the common questions in
[interview-questions.md](../interview-questions.md). Project numbers match
[project-classification.md](../project-classification.md).

- [ ] Who is the partner organization or person?
- [ ] Which families is it for (age range, needs, geographic area)?
- [ ] Does a list of resources exist already, and in what form?
- [ ] Who decides what gets listed, and who keeps it current?
- [ ] Is there a domain name or hosting budget?
- [ ] What accessibility needs must the site meet?
- [ ] Should families be able to submit resources?
