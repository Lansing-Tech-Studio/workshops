# Learn More

Want to keep going after the robotics camp? This is a collection of places to learn
more about the robot, the code, and what to build next. You don't need any of these
to finish the camp — they're here for when you're curious and want to dig deeper.

> **The robot says:** Pick _one_ link that sounds interesting and try it this
> week. You don't have to read everything — momentum over perfection!

## Pybricks (Our Robot's Brain)

The software we use to program the robot. These pages change sometimes, so if a link
breaks, search for the title to find the new location.

- [Pybricks home](https://pybricks.com/) — what Pybricks is and which LEGO hubs it works with
- [code.pybricks.com](https://code.pybricks.com) — the in-browser editor we use in camp
- [Pybricks documentation](https://docs.pybricks.com) — the full reference for every
  block and Python command (DriveBase, motors, sensors, the gyro, and more)
- [Installing Pybricks firmware](https://pybricks.com/learn/getting-started/install-pybricks/) —
  the one-time setup an instructor does for each hub

## Robot Commands We Used

The exact tools behind this week's missions.

- [DriveBase](https://docs.pybricks.com/en/stable/robotics.html) — drive a distance,
  turn an angle, and use the gyro (Sessions 1–3)
- [Motors](https://docs.pybricks.com/en/stable/pupdevices/motor.html) — control a
  single motor directly
- [Ultrasonic (distance) sensor](https://docs.pybricks.com/en/stable/pupdevices/ultrasonicsensor.html) —
  the "eyes" from Day 4
- [Color sensor](https://docs.pybricks.com/en/stable/pupdevices/colorsensor.html) —
  reflected light and color for line following (Day 5)
- [The hub and its gyro (IMU)](https://docs.pybricks.com/en/stable/hubs/primehub.html) —
  reading a heading (Day 3)

## Programming Ideas

The coding concepts behind the robot work everywhere, not just in robotics.

- [Python for beginners](https://www.python.org/about/gettingstarted/) — the language
  behind the text-coding track
- [W3 Schools — Python tutorial](https://www.w3schools.com/python/) — beginner-friendly
  lessons on loops, `if`/`else`, and functions
- [code.org](https://code.org/) — block-based coding practice if you liked the block track

## Going Further with Robotics

- [LEGO Education SPIKE Prime](https://education.lego.com/en-us/products/lego-education-spike-prime-set/45678/) —
  more about the hardware and official building ideas
- [FIRST LEGO League](https://www.firstlegoleague.org/) — a team robotics program many
  students join after camp
- [Pybricks examples](https://docs.pybricks.com/en/stable/examples/index.html) — sample
